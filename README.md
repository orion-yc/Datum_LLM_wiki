# 知序 · Datum Knowledge Studio

可私有部署的中文学习与研究知识库。所有产品交互在网页完成；**后端全部采用 C++20**，提供认证、团队权限、SQLite 持久化、文档解析、检索、模型调用与论文工作流。前端采用 React / TypeScript。

## 已实现

- **资料与阅读**：PDF / Markdown / TXT 上传、解析、错误重试、PDF 预览、目录、阅读进度、原文定位和笔记；资料库批量勾选、筛选全选、删除影响预览与逐项结果。
- **可选 AI 版面解析**：双栏 / 三栏论文、表格和扫描 PDF 按页发送视觉模型；后台串行处理，原始 PDF 对照、编辑校对后采用；保留已有笔记和引用的历史片段。
- **知识与技能**：知识点草稿、标签、先修关系与循环检测、合并、技能标准和实践证据。
- **知识 Wiki**：跨资料整理概念 / 方法 / 综述，可编辑草稿、原文证据、关联与反向链接、核对发布、版本恢复、Markdown 导出；讨论与任务直接关联知识页。
- **知识质量与检索**：检查未整理资料、缺少证据、引用编号、孤立页、同名页和未解决讨论；原文与已发布 Wiki 双路检索，保留知识页引导线索，上传内容指纹去重。
- **学习与问答**：计划与步骤、回想练习、自评和复习日期、原文问答与来源引用。未配置模型时仍可检索、学习与自评。
- **模型推理强度**：网页选择服务商默认、none、minimal、low、medium、high、xhigh 或 max；配置持久保存，统一应用于问答、知识点 / Wiki 生成、练习反馈与论文对比。
- **团队权限**：独立账号、所有者 / 管理员 / 编辑者 / 只读成员、一次性邀请、成员停用、角色调整、密码重置和所有权转移。
- **多人协作**：资料、知识点、计划和论文的共享讨论；评论解决状态；负责人、截止日期和任务看板；操作归属。网页携带版本号，过期保存返回 409。
- **论文研究**：论文元信息与方法 / 数据集 / 指标 / 局限性阅读记录；2–8 篇论文、1–12 维对比矩阵；每格原文证据；待核对草稿生成；指定审核人；草稿 → 审核 → 发布；版本快照、恢复与 Markdown 导出。
- **数据管理**：scrypt 密码散列、AES-256-GCM 密钥加密、管理员 JSON 导出、旧 SQLite 自动升级。

一套部署对应一个团队。团队内资料、笔记、学习记录和对话共享；当前没有多租户空间、私有资料夹或按文档单独授权。

## 从资料到 Wiki

1. 在“我的资料库”上传书籍、论文或笔记。
2. 打开“知识 Wiki → 从资料整理”，选择主题和 1–8 份资料。
3. 阅读生成范围，编辑草稿，补充原文证据和关联页；没有模型时可直接手动整理。
4. 保存、核对 `[1]` 等引用，处理讨论后发布。
5. 在“和知识对话”查询，答案仍引用原文，并显示哪些 Wiki 帮助找到了证据；定期在“质量检查”处理待整理提示。

也可手动建页。Wiki 整理跨资料知识，原有“知识与技能”记录熟练度和实践进度。GitHub 参考源码、采纳思路与实现边界见 [Wiki 设计说明](docs/wiki-design.md)。

在“互联网学习”中粘贴公开 GitHub 仓库、目录或文件链接，后台按提交建立可更新的文本索引。可跟随学习路线读带行号源码、查证据、记学习进度，并将具体代码行与 Wiki 或知识点双向关联。导读和问答可使用已配置的模型；导入不会执行仓库代码。见 [项目学习设计](docs/internet-project-learning-design.md)。

## 模型与推理强度

所有者或管理员进入“空间设置 → 模型连接”，填写 API 基础地址、模型名称与密钥，选择“推理强度”，点击“保存并测试连接”。设置对整个团队空间生效，刷新网页和重启服务后保留。

“服务商默认”不发送 `reasoning_effort`，兼容原有模型请求；`none` 则显式请求不推理。其他档位从 minimal 到 max 表示不同推理强度，支持范围取决于模型和服务商。强度较高通常需要更多时间与 token；不支持时网页会提示选择模型支持的档位或使用服务商默认，不会自动降低你选定的强度。

显式指定强度时，C++ 后端发送 Chat Completions 的 `reasoning_effort`，省略 `temperature`，为推理与回答合计预留 token 上限：连接测试 4096、正式生成 32768。测试超时 60 秒，正式请求 180 秒。优先使用 `max_completion_tokens`；仅当上游 HTTP 400 / 422 明确拒绝该参数时，保留相同强度并用 `max_tokens` 重试一次。实际模型服务仍需通过网页连接测试确认兼容性。

## 资料库批量管理

进入“我的资料库 → 批量管理”，勾选资料或选择当前筛选结果，可跨用途分类保留选择，每批最多 100 份。点击“批量删除”先查看文件、笔记数量及关联限制，确认后一次删除可删除的资料。

资料正在普通解析，或仍被论文档案 / Wiki 原文证据引用时暂不删除，网页会显示原因和具体标题。其他资料照常删除，完成后显示成功与未删除清单，保留未删除项目的选择，便于处理关联后重试。执行时重新检查引用与版本，其他成员刚更新的资料不会被过期确认删除。

删除会清理原文件、正文、资料笔记、AI 解析任务、预览、资料讨论和任务；知识点、学习计划与对话保留并解除资料关联。删除不可撤销。只读成员没有批量管理入口，后端同时拒绝其批量预览和删除请求。

## 多栏论文与扫描 PDF

普通解析默认启用，不调用模型，使用 Poppler 的阅读顺序模式。复杂版面仍可能出现错序，可选择 AI 解析：

1. 管理员在“空间设置”连接支持图片输入的 Chat Completions 服务。可填写“PDF 视觉解析模型”，与默认模型共用 API 地址、密钥和推理强度；留空则复用默认模型。
2. 上传 PDF 时勾选“启用 AI 版面解析”，选择前多少页或整份 PDF；已上传资料可在阅读页点击“AI 版面解析”，选择整份文档或连续页码范围。AI 文档页数上限 10,000 页。
3. 后台逐页渲染并调用模型，关闭网页后继续处理。全实例只同时调用一次视觉模型，新任务每处理 5 页让出调度机会；可暂停、继续和取消，重启后续跑并跳过已经保存的页面。
4. 在网页逐页对照原始 PDF、查看模型提示，必要时编辑 Markdown，点击“已核对，采用所选页解析”。仅更新所选页面，随后用于阅读、检索和新知识生成；原有笔记、Wiki 和论文证据保留历史引用。

页面图片会发送至配置的服务并产生相应费用，公式、数字、图表需要人工核对。AI 结果先作为待采用草稿，完成页即可分批核对采用，每批最多 50 页。失败后点击“继续未完成页面”，成功页不重复调度。旧版本任务保留原来的重启中断行为，不在升级后自动调用模型。只读成员可以查看已有结果，编辑者和管理员可以发起、取消、校对和采用。

增量解析跨任务复用同一 PDF 的最近成功结果，扩大范围或重新打开任务时只调用缺页；旧结果来自不同模型时显示原模型来源，想重做时明确勾选“重新解析所选页”。已保存的校对正文、核查标记和采用状态一并保留。原文件内容不变时无需反复解析。

核查可逐页保存、核查并采用本页，或输入任意页码范围标记已核查，再点击“采用全部已核查页”一次处理全部完成页。页面列表每次加载 50 条仅为减少传输和内存，用户核查 / 采用的总数不受 50 页限制；后台顺序提交小批事务，失败时显示已成功页数，重试只处理剩余已核查页。未保存的校对在切页或关闭弹窗时保存；已保存记录跨刷新和重启保留。多人保存使用版本号校验。

PDF 阅读目录按物理页码合并，同页多个检索片段只显示一个目录入口，点击正文任一片段仍高亮所属页，历史原文引用保持可定位。

后端使用 C++ 工作线程、SQLite 和 Poppler `pdfinfo` / `pdftoppm`，逐页生成最长边 2000 像素的 JPEG，无需本地 OCR 或模型框架。队列最多容纳 12 个待处理任务；低内存机器建议先选择少量页面。默认推理强度下，页面输出预算 8192 token；显式强度沿用 32768 总预算，单次请求超时 180 秒。预览图缓存最多约 512 MiB，清理后按需从原 PDF 再生成，不调用模型。普通提取仍保留 2,000 页 / 40 MiB 输出上限，AI 采用保留 15,000 个活动正文片段的容量保护；遇到容量提示需拆分资料。实际识别效果取决于视觉模型，建议先试 1–3 页。

## Docker Compose 部署

服务器只需 Docker 与 Compose。构建阶段编译网页和 C++ 程序，运行容器不包含 Node.js。

```bash
cp .env.example .env
docker compose up -d --build
docker compose logs --tail=80 app
```

默认宿主机地址为 `127.0.0.1:3001`。通过 SSH 隧道或可信反向代理进入网页，创建所有者账号，然后在“团队协作”中邀请成员。无默认密码。Nginx 与参数说明见 [部署文档](docs/deployment.md)。

## 原生构建

已部署服务器的域名、服务管理及备份说明见 [onnotify 服务器运维](docs/server-onnotify.md)。

需要 CMake ≥ 3.21、C++20 编译器、Qt 6.4+ Core / Network / Sql 及 SQLite 驱动、OpenSSL、libarchive 开发库和 Poppler `pdftotext` / `pdfinfo` / `pdftoppm`。不需要 Qt Widgets 或桌面。Node.js 24.x / pnpm 11.25.0 仅用于前端构建、开发工具和测试。

Debian 12 / Ubuntu：

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake qt6-base-dev libqt6sql6-sqlite libssl-dev libarchive-dev poppler-utils poppler-data
pnpm install --frozen-lockfile
pnpm build:all
./build/backend/datum-server
```

程序直接提供 `dist/` 网页和 `/api`。启动时工作目录为项目根目录，也可用 `STATIC_DIR` 和 `DATA_DIR` 指定绝对路径。

```bash
pnpm build:backend
pnpm dev
```

开发网页在 `http://localhost:5173`，代理 API 到 3001。修改 C++ 后需重新编译并重启。

Windows 可安装 Qt MinGW、CMake、Ninja、OpenSSL、libarchive 和 Poppler。libarchive 需与 Qt 使用相同的 MinGW 工具链，其安装前缀可加入 `CMAKE_PREFIX_PATH`，运行时 DLL 目录加入 `PATH`。构建脚本发现常见 Qt 目录，也可显式设置 `QT_ROOT`、`MINGW_ROOT`、`CMAKE_PREFIX_PATH`、`OPENSSL_ROOT_DIR`、`PDFTOTEXT`。原生进程不自动加载 `.env`，该文件供 Compose 使用。

## 旧版升级

保留原 `data/` 或数据卷。首次启动 C++ 版本会在 `data/backups/` 创建升级前数据库和密钥副本，保留资料、笔记、知识点及模型配置，将旧访问密码迁为所有者账号 **admin**，原密码继续有效，旧会话失效。

升级前仍应停止旧服务并完整备份。回退旧程序需同时恢复升级前数据库和密钥，不能让两个版本同时访问同一数据库。

v0.2 升至 v0.3 也会先备份，保留原账号，补建 Wiki 表和旧文件指纹。自动升级不会创建内容或删除重复资料。

增量 AI 解析与持久核查将数据库模式升级为 7，升级前同样自动备份，新增后台任务和页面结果，原有正文全部保留为当前版本。JSON 导出包含解析任务、页面结果及历史片段，不包含原始文件或模型密钥。

## 验证

```bash
pnpm build:all
pnpm test
pnpm test:e2e
```

浏览器测试需 Chromium：`pnpm exec playwright install chromium`。测试使用隔离 C++ 进程和临时数据库。范围和部署验证状态见 [验证记录](docs/verification.md)。

```text
backend/src/         C++ HTTP、认证、迁移、解析、检索、Wiki、协作、论文工作流
backend/third_party/ 固定版本 cpp-httplib 与许可证
src/                React 网页
scripts/            构建和浏览器验收工具
tests/              核心、API、Wiki、团队、论文、旧版迁移测试
deploy/             Nginx 示例
docs/               部署、验证与需求
data/               运行数据，已排除 Git
```

PDF 使用原生 C++ Poppler 工具解析，扫描件可按需使用 AI 视觉解析或先 OCR。模型回答与论文草稿需要人工核对；未配置模型时只提取原文。单文件最多 250 MB、每批 5 份；大文件以 1–4 MB 自适应分块上传，兼容 Cloudflare 的 100 MB 单次请求限制，论文生成使用每篇前 120 个片段。依赖许可证见 [第三方说明](docs/third-party.md)。

Wiki 生成每份资料最多使用 4 个片段，并在网页展示范围。检索为本地 BM25 与已发布 Wiki 证据关系融合，尚未接入向量检索；质量检查为规则检查，语义矛盾需人工判断。


大文件分块遇到临时网络错误或代理 504 时自动重试。连续失败后，保持当前文件选择，再点上传会查询服务器已保存的偏移并续传；上传任务一小时过期。此恢复针对当前网页中的文件选择，不代表关闭浏览器或换设备后自动续传。重新发送已保存的相同分块安全返回成功，不重复写入。
