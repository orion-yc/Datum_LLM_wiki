# 项目源码阅读工作台

状态：工作台、Markdown 与图片预览、按需翻译已实现。适用范围：互联网学习 → 源码阅读。

## 目标

做一个接近 VS Code 的只读学习工作台：找文件、连续读代码、读带图片的项目文档、对照翻译，再把原文绑定到知识点。不是在线 IDE，不执行仓库代码，不引入终端、扩展市场、编辑提交或语言服务器。

现有阅读将所有文本展示为每次 120 行的纯文本，路径列表不具备目录结构，图片归为不可索引文件。保留带提交和行号的证据模型，替换阅读体验，而不是更改知识关联的数据含义。

## 布局与交互

| 区域 | 第一版 |
| --- | --- |
| 顶部 | 项目、提交选择、路径面包屑、已打开文件标签。进入源码阅读后隐藏非必要项目标题和营销式留白。 |
| 左栏 | 可折叠目录树，按需加载子目录；文件名搜索定位到树中。关闭后给阅读区让位。 |
| 中栏 | 代码、Markdown、图片分别用专用预览；同一文件切换模式时保留阅读位置。 |
| 右栏 | 按需打开大纲、翻译、代码解释、知识关联之一，默认收起。不常用按钮放进菜单。 |
| 底部 | 行列、选区、文件类型和只读状态。文件返回后恢复位置；浏览器前进或后退还原选中的路径。 |

桌面支持调整边栏宽度和专注模式。中小屏先收起右栏，小屏将目录和翻译作为单独的抽屉，主区域保持单栏。标签可以关闭、切换；按项目和提交在当前浏览器保存最近打开文件与阅读位置。打开失败时保留标签位置，提供针对该文件的重试。

## 文件阅读

- **代码**：桌面优先采用 Monaco Editor 只读模式，支持语法高亮、行号、缩进线、折叠、文件内查找、跳行、复制选区及链接。大文件超过实测阈值时保留分段接口并按需滚动加载，避免整页渲染。暂不承诺 C++ 精确跨文件跳转、运行调试或 VS Code 扩展兼容；手机保留轻量阅读器。
- **Markdown**：默认渲染标题、目录、表格、任务列表、代码块和图片，提供 Markdown 源文及原文/译文切换。目录中的相对链接解析到同一提交中的相对文件，锚点可跳转；超出导入范围的文件提示并提供固定提交的 GitHub 链接。页面允许标准 Markdown，不执行仓库提供的 HTML 或脚本。
- **图片**：文件树可直接打开 PNG、JPEG、WebP、GIF，Markdown 中同仓图片内联展示，支持适配、原始大小。图片不进入正文检索，也不占用正文限制；独立校验实际格式、体积与像素尺寸，超过阈值保留原始地址。SVG 第一版仅给原图链接，不直接作为活动文档渲染；后续可加隔离栅格化。
- **老项目**：复用旧快照路径和 blob 指纹。已索引的 Markdown 原文直接渲染；图片从同一提交按需补缓存，不要求删除或重导 OpenCV。浏览器请求的是本站资源，不能依赖客户端直连 GitHub。

## 翻译与知识

- Markdown 默认支持点击翻译当前章节，原文、中文、双栏对照三种模式。文档译文按段与原文对齐，保留代码块、命令、URL、路径、标识符；先展示已完成章节，可继续其他章节或单独重试失败章节。
- 源码选区有两个独立动作：「翻译注释」保持含义一致；「解释这段代码」可说明职责、输入输出、相关定义和可能的理解陷阱，注明推断。结果放侧栏，不改动源码，也不改行号。
- 译文使用已配置模型，由用户主动触发并标记为 AI 译文。无模型或模型失败时保留原文与预览，可重试，默认不在打开文件时发起模型调用。
- 缓存按 blob 内容指纹、原文段落、目标语言、模型和提示词版本区分；同一版本重复打开不再翻译，仓库更新时未变内容可复用。不将译文自动写入 Wiki、搜索正文或学习记录。
- 文件行号、Markdown 标题和段落的引用均回指原始提交和原文范围。可以直接从选区创建 Wiki / 知识点关联。仓库更新后不重写旧引用，也不拿译文行号当证据。

## 数据与资源

- 目录使用版本和父目录分页，不把 OpenCV 的整棵树一次传到手机。文本按需加载，桌面 Monaco 延迟导入，非阅读页面不下载编辑器；原有行段接口和旧版路线链接兼容。
- 图片缓存从已知提交和 Git 树中的路径获取，保留现有 GitHub 主机限制，不做代理外部任意 URL。远程徽章、外站追踪图默认不自动加载；不从浏览器收到的任意地址抓取。按 blob 去重、总量受限、超限淘汰。
- Markdown 转换走结构化解析，不用正则直接插入原始 HTML。资产响应检查权限，校验字节指纹和内容类型；路径不能越过仓库或用链接绕开项目范围。
- 翻译以章节或选区为单位排队，限制并发、字符预算和输出体积。文档及代码只作为输入资料，不把仓库里的文字当成模型操作指令。

## 实施与验收

1. 先交付文件树、标签、代码阅读和旧引用定位，验证大项目打开和连续滚动。
2. 在同一阅读器内交付 Markdown 和图片，验证相对链接、旧快照按需补图、格式安全。
3. 接入按需翻译、双栏对照与代码解释，验证同一内容命中缓存、模型异常可恢复，引用仍回原文。

用正式站点已有的 OpenCV 项目在隔离环境验收：连续看长 C++ 文件，README 切换源文和预览，从文档打开同提交的图片，翻译一节，最后从 Wiki 返回原始行号。覆盖桌面与手机；低内存构建串行执行，实际性能通过测试确认，不在设计阶段承诺固定耗时。
