## 2026-11-18：上传 504 恢复与速度优化

生产 Caddy 日志显示 109 MB PDF 在偏移 50,331,648 字节处传输 8 MiB 分块时，上游写入超时返回 504；网页此前将非 JSON 响应显示为笼统错误，并删除临时任务。改为 1 MiB 起步、快速响应时增到最多 4 MiB 的自适应分块，慢请求缩小，临时错误回退到 1 MiB 并按 1 / 2 / 4 秒退避最多重试三次。显示实际上传速度和估算剩余时间，区分文件传输与解析。

新增读取上传偏移接口，沿用成员归属校验。重复分块在位置、长度和内容一致时安全确认成功，内容不同仍拒绝。前端重试耗尽后保留任务，当前文件选择不变时重新点击上传从服务端偏移继续；未实现刷新浏览器、重新选择文件或换设备自动恢复。代理错误保留 HTTP 状态和超时原因。

C++ / TypeScript / Vite 构建通过，25 组后端测试通过。最终自适应版本重新通过三组上传 API 验收、故障浏览器验收和 198 MB PDF 实际上传 / 解析 / Range 读取验收。模拟分块已保存后响应丢失、连续 504、再次点击上传续传，最终只生成一份资料；相同 207,952,623 字节文件请求数从固定 1 MiB 的 199 次降到 51 次，不能据此推断公网带宽或固定倍数提速。构建及测试串行并受 650 MiB 限制。

- 未做大规模压力测试、多租户隔离或按文档访问控制。本版本明确是一套部署一个共享团队。
