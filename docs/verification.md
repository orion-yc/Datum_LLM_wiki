# 初版验收记录

验收日期：2026 年 11 月 13 日。环境：Windows、Node.js 24.22.1、Chromium，浏览器时区为 Asia/Shanghai。

## 已通过

- `pnpm build`：TypeScript 类型检查和 Vite 生产构建。
- `pnpm test`：5 项测试通过，包含完整 API 集成测试。
- `pnpm test:e2e`：10 组浏览器流程通过，无浏览器运行时异常。
- `pnpm audit --prod`：执行时未发现已知生产依赖漏洞。

API 验收覆盖：未登录拒绝访问、首次密码设置、会话与跨站请求检查、中文 Markdown 上传、英文 PDF 与依赖 CMap 的中文 PDF 提取、解析失败与重试、阅读进度、笔记更新、知识点草稿与确认、先修关系验证、技能与计划、真实引用与无依据回答、练习自评与历史保留、模型连接与失败处理、密钥不以明文落库、数据导出、知识点合并，以及服务重启后的数据与会话恢复。

浏览器验收覆盖：

1. 首次初始化和空资料库。
2. 原创示例阅读、知识点草稿、笔记、进度与刷新恢复。
3. 知识点确认、编辑与技能创建。
4. 学习计划创建和步骤完成。
5. 问答、引用跳转与返回历史对话。
6. 练习作答、自评、复习与历史记录。
7. 网页设置和 JSON 导出。
8. 网页文件选择、用途分类和真实上传。
9. 首页统计与全局搜索。
10. 390px 手机布局、导航与横向溢出检查。

桌面截图为 1440px 宽，手机截图为 390px 宽。截图保存于 `test-results/`，截图中的资料和学习数据仅用于验收，正式资料库未预置账号或内容。

## 需要服务器上的最终验证

- 当前机器没有 Docker，未执行镜像构建和容器运行。已提供 Dockerfile、Compose、Nginx 示例及备份恢复说明。
- 模型接口使用本地模拟服务验收，没有使用真实服务商密钥。真实模型需在网页保存配置并测试连接。
- 未连接用户的远程服务器、域名或 HTTPS 证书，也未执行远程发布。
- 尚未进行多人并发、大规模资料库或不同操作系统浏览器兼容性测试。
